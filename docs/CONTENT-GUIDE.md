# Content guide

Every scenario must include an ID, module, tier, learning objective, item type, competency tags, title, brief, task, answer, correct and incorrect feedback, citations, and review metadata.

Terminology placeholders must use the centralized vocabulary in `src/terminology.js`; unresolved placeholders fail validation.

New badges require at least two independent pieces of evidence. Where practical, evidence should span more than one item type and more than one context.

New visual exhibits must provide a useful text description and structured table or list representation. Decorative variety alone is not sufficient reason to add a chart.
