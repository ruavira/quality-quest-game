# Quality Quest participant guide

## Open the app

Visit **https://quality-quest.pages.dev/** in Chrome or Microsoft Edge.

Do not download or double-click `index.html`. Quality Quest is an installable web app: the secure web address performs the first installation and downloads the offline content.

If the pilot is protected by Cloudflare Access, enter the email address authorized by the programme and complete the one-time-code sign-in. Keep the first visit online until the Quality Quest welcome screen appears.

## Install on a computer

1. Open Quality Quest in Chrome or Microsoft Edge.
2. Select **Install Quality Quest** when the in-app installation message appears.
3. If the message does not appear, use the browser's installation icon at the right of the address bar, or open the browser menu and choose **Install Quality Quest** / **Apps → Install this site as an app**.
4. Confirm **Install**. Quality Quest will then open in its own window and appear with the other applications on the computer.

## Install on a phone or tablet

- **iPhone or iPad:** Open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** Open the link in Chrome, then select **Install app** or **Add to Home screen**.

## Offline use and progress

- Complete one successful online load before going offline.
- Progress, reflections, and badges stay in that browser profile on that device.
- Do not clear the browser's site data if progress must be retained.
- Use **Case File → Download transcript (JSON)** to keep or share a learner-controlled record.
- If the Cloudflare access session expires, reconnect to the internet and sign in again before refreshing the installed app.
