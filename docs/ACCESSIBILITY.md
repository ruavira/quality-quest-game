# Accessibility

The product is designed toward WCAG 2.2 AA but does not claim full conformance until manual assistive-technology testing is complete.

Implemented safeguards include:

- semantic headings, labels, controls, and progress information
- 44-pixel minimum interactive targets
- visible keyboard focus, including SVG data points
- keyboard selection and traversal for interactive run-chart points
- chart descriptions and structured table/list alternatives
- no hover-only tasks
- reduced-motion support
- non-colour text descriptions of signals and limits
- printable Case File

Release validation must include VoiceOver and NVDA walkthroughs, 200% zoom, keyboard-only completion, colour-vision simulation, and mobile touch testing. Chart interaction remains the highest-risk surface.
